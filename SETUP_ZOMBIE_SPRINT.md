# 🎮 Zombie Sprint Setup - Quick Guide

## What You Need to Know

**Zombie Sprint** is a 3D kart racing game - much more complex than simple lane-following driving games. This requires:

1. **More sophisticated AI** (9 actions including drift and powerup)
2. **Frame stacking** (4 frames to perceive motion)
3. **Longer training** (2000 episodes vs 1000)
4. **Different rewards** (position-based, not just lane-following)

---

## 🚀 Setup in 5 Minutes

### Step 1: Install Dependencies (2 minutes)

```bash
pip install torch torchvision opencv-python numpy Pillow

# For GPU (10-20x faster):
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

### Step 2: Verify Installation (30 seconds)

```bash
python -c "import torch; print('PyTorch:', torch.__version__); print('CUDA:', torch.cuda.is_available())"
```

Should see:
```
PyTorch: 2.x.x
CUDA: True  # If you have GPU
```

### Step 3: Check Configuration (30 seconds)

```bash
python config_zombie_sprint.py
```

Should display game settings and instructions.

### Step 4: Open Game (1 minute)

1. Go to: https://www.onlinegames.io/zombie-sprint/
2. Click "Choose Your Zombie"
3. Select **"Grave Sprinter"** (light zombie)
4. Click "Choose a Route"  
5. Select **"Graveyard Loop"** (easy track)
6. Set **"Easy"** threat level
7. **DON'T START RACE YET**

### Step 5: Position Browser (30 seconds)

1. Move browser to **TOP-LEFT** corner of screen
2. Resize so game area is approximately **1000x800 pixels**
3. Make sure you can see the track clearly

### Step 6: Start Training (30 seconds)

```bash
python train_zombie_sprint.py
```

1. You'll see a 10-second countdown
2. **NOW click "Start Run" in the game**
3. Training begins automatically!

## 🎯 Success Checkpoints

### After 100 Episodes (30 min)
✅ Should complete at least 1 lap before crashing  
✅ Mostly staying on track  
❌ Still finishing last (7th-8th)

**If not**: Check game is positioned correctly, run `pds.py` to test vision

### After 500 Episodes (2 hours)
✅ Completes 3 laps consistently  
✅ Finishes in middle pack (4th-6th)  
✅ Basic cornering working

**If not**: Reduce off-track penalty, increase on-track reward in `config_zombie_sprint.py`

### After 1000 Episodes (4 hours)
✅ Podium finishes (top 3) regularly  
✅ Uses drift through corners  
✅ Overtakes opponents

**If not**: Train longer, agent needs more experience

### After 2000 Episodes (6 hours)
✅ Wins races (1st place) 40%+ of time  
✅ Optimal racing lines  
✅ Strategic play

**If not**: Adjust hyperparameters, see troubleshooting

## 🛠️ Quick Fixes

### Problem: Agent drives off track constantly

**Fix 1**: Increase penalty
```python
# Edit config_zombie_sprint.py
REWARD_CONFIG['off_track'] = -10.0  # Was -5.0
```

**Fix 2**: Train longer (needs 200+ episodes to learn basics)

### Problem: Agent never wins

**Fix 1**: Train much longer (needs 1500+ episodes)

**Fix 2**: Increase position rewards
```python
REWARD_CONFIG['position_1st'] = 20.0  # Was 10.0
```

### Problem: Training is very slow

**Fix 1**: Install CUDA PyTorch for GPU
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

**Fix 2**: Reduce frame size
```python
# Edit config_zombie_sprint.py
VISION_CONFIG['resize_dims'] = (64, 64)  # Was (84, 84)
```

### Problem: Loss becomes NaN

**Fix**: Reduce learning rate
```python
# Edit config_zombie_sprint.py
TRAINING_CONFIG['learning_rate'] = 0.00005  # Was 0.0001
```

## 🆘 Emergency Stops

### Stop Training

- **Press 'q'** in OpenCV window, OR
- **Press Ctrl+C** in terminal

Model is auto-saved, you can resume later.

### Resume Training

Currently not automatic. To continue:

1. Load model in `train_zombie_sprint.py`
2. Adjust starting episode number
3. Run training again
